# Pitch deck

Source for the HelloHacks 2026 pitch deck: `deck.json` (outline, fonts, slide
order) plus one `slides/<id>.html` file per slide, in the same format the
deck's own live editor saves. `images/` holds real screenshots of the app
(the web dashboard's Overview and Calendar screens), referenced by the
slides with relative paths.

This is a snapshot of the deck's content for version control - the deck
itself is live-edited elsewhere, not from this repo. If you want to keep
editing it with drag/resize/retype in a browser rather than by hand, ask
whoever has it for the live link rather than editing these files directly.

## Presenting

- **5-minute order and timed script:** `SPEAKER-NOTES.md` (slide ids match `deck.json`).
- **PowerPoint export with speaker notes:** `keynote/`. The source here is canonical; regenerate the export after edits.
