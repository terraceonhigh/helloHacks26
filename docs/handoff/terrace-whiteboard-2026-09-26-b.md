## Asks

## BLUF
- **The human is the subagent.**
- **The pane is the prompt list**, one row per item.
- **A row is a prompt:** no other context should be needed to do the item. (This is aspirational.)

## The student loop
1. Sleep, then wake.
2. **Check the pane**, then click an item on it.
3. **Everything is ready** (readings and so on), so the student works.
4. Click the Canvas (or other platform) submit link on the pane, and submit.
5. **More tasks?**
   - Yes: go back to checking the pane.
   - No: sleep.
