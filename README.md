# helloHacks26

**▶ Try it live: [hello-hacks26-terraceonhigh.vercel.app](https://hello-hacks26-terraceonhigh.vercel.app/)**. No install needed; it opens on sample data.

Single pane of glass for students: Canvas, Workday, the UBC Bookstore, and beyond in one place

# Core value proposition: 
- Students currently face significant administrative overhead when organizing courses, navigating various platforms, and doing setup.
- We've built a platform to allow students to do everything they need to do as a student in one app.
